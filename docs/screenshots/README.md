# Screenshots

Screenshots here document the finished application. Run `pnpm dev` (or the production build), open the app, and capture the states below in a desktop viewport (ideally 1440px wide) and also a mobile viewport (390px) for the responsive states.

These images are referenced from the [README](../../README.md). They must show the real, running application rather than mockups.

## Desktop states to capture

- Landing page
- Projects grid view
- Projects list view
- Multi-selection with the selection toolbar
- Command preview (generated commands)
- Command palette
- Launch Sets
- Settings
- A theme variation different from the default

## Responsive / mobile states to capture

- Projects view with the bottom navigation bar
- A dialog in its bottom-sheet form
- The command palette in its mobile form

## Naming

Use `kebab-case` descriptions, e.g. `projects-grid.png`, `projects-multi-select.png`. Reference them from the README with relative paths.
